## Run locally

Requires Node.js and npm.

git clone https://github.com/CebisaE/emihle-portfolio.git
cd emihle-portfolio
npm install
npm run dev

Open the local address printed in the terminal.

## Production build

npm run build

Vite generates the production website in the dist directory.

To preview that build locally:

npm run preview
